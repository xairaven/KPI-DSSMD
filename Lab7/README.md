# Лаб. 7 — Абітурієнт (найближчий заклад)

Android-додаток на Tauri (Rust + React/TypeScript), побудований на основі
Лаб. 6. Домен: абітурієнт (ID, Прізвище, Ім'я, По-батькові, Адреса,
Телефон, Оцінки).

Завдання — додати визначення найближчого об'єкта, здатного надати
потрібний програмі сервіс, відповідно до логіки її роботи. Для домену
"Абітурієнт" таким об'єктом обрано **навчальний заклад (приймальну
комісію)**: за поточним розташуванням пристрою застосунок визначає
найближчий із переліку університетів, завантаженого з файлу.

## Структура

- `src-tauri/src/applicant.rs` — Model: сутність `Applicant` і чисті
  функції бізнес-логіки (середній бал, незадовільні оцінки, поріг,
  напівпрохідний бал). Нічого не знає про Tauri чи UI.
- `src-tauri/src/repository.rs` — Model: спільне мутабельне сховище
  (`Mutex`, керований стан Tauri) у пам'яті, ініціалізоване даними з БД.
- `src-tauri/src/sample.rs` — початковий масив із 10 абітурієнтів,
  яким заповнюється щойно створена (порожня) база даних при першому
  запуску.
- `src-tauri/src/storage.rs` — Model: читання/запис абітурієнтів у
  SQLite-базі (`applicants.db`) у каталозі даних застосунку.
- `src-tauri/src/geo.rs` — чиста функція `haversine_km()`: відстань
  по великому колу між двома координатами. Нічого не знає про Tauri
  чи джерело координат.
- `src-tauri/resources/institutions.json` — перелік університетів
  (назва, адреса, широта, довгота), що постачається разом із
  застосунком як Tauri-ресурс і підвантажується з файлу під час
  виконання команди — на відміну від `sample.rs`, тут немає жорстко
  закодованого в Rust масиву.
- `src-tauri/src/screen/` — Controller: по одному модулю на кожен пункт
  завдання плюс екран введення/редагування, генерація QR-коду та пошук
  найближчого закладу:
  - `failing.rs` → (a) незадовільні оцінки
  - `threshold.rs` → (б) поріг середнього балу
  - `top.rs` → (в) топ-N та напівпрохідний бал
  - `students.rs` → список, додавання, редагування, видалення
  - `qr.rs` → генерація SVG QR-коду з даними одного абітурієнта
  - `nearest.rs` → (новий у цій роботі) команда
    `find_nearest_university(lat, lon)`: читає `institutions.json`
    через `tauri-plugin-fs` (на Android bundled-ресурси лежать
    усередині APK і недоступні напряму через `std::fs` — плагін сам
    маршрутизує `asset://`-шляхи через `AssetManager`) і повертає
    найближчий заклад, обчислений через `geo::haversine_km`.
- `src-tauri/src/lib.rs` — читає `applicants.db` під час `setup()`,
  реєструє `tauri-plugin-fs` для всіх платформ і `tauri-plugin-geolocation`
  лише на мобільних (`#[cfg(mobile)]`), підписується на
  `RunEvent`/`WindowEvent`, щоб журналювати зміни стану життєвого циклу
  Activity, і зберігає повний знімок даних у базу при
  `Suspended`/`Exit`/`CloseRequested`.
- `src-tauri/capabilities/default.json` — дозволи `core`, `opener` та
  `fs` (читання ресурсів) для всіх платформ.
- `src-tauri/capabilities/mobile.json` — окремий файл дозволів,
  обмежений `"platforms": ["iOS", "android"]`, для команд
  `tauri-plugin-geolocation` — вони недоступні як залежність на
  десктопі, тож перевірка дозволів під час збірки десктопної версії
  провалилася б, якби ці дозволи лишались у `default.json`.
- `src/screens/` — View: `Home.tsx` (меню), та по одному екрану на
  кожен Controller вище. Жодної бізнес-логіки, лише відображення та
  виклик `invoke()`.
  - `Search.tsx` — нечіткий (typo-tolerant) пошук абітурієнтів за
    прізвищем через `fuse.js`.
  - `Students.tsx` — список/форма, а також кнопка "QR-код" у кожному
    рядку, що показує SVG QR-код з даними абітурієнта.
  - `Nearest.tsx` — (новий у цій роботі) запитує дозвіл на
    геолокацію та поточну позицію через `@tauri-apps/plugin-geolocation`
    (з `enableHighAccuracy: true` — на емуляторі мережевого
    розташування немає, лише GPS-фікс, внесений через Extended
    Controls), передає координати в `find_nearest_university` і
    показує назву, адресу та відстань до найближчого закладу.
- `src/components/ApplicantTable.tsx` — спільна таблиця, яку
  перевикористовують екрани звітів (a/б/в).

## Запуск

```sh
pnpm install
pnpm tauri android dev   # Android-емулятор
pnpm tauri dev            # десктоп, для швидкої перевірки
```

### Перевірка

На емуляторі увімкніть геолокацію та задайте координати через Extended
Controls → Location (наприклад, Київ). На екрані "Найближча приймальна
комісія" натисніть "Визначити розташування" — застосунок має показати
найближчий університет зі списку (для Києва — КПІ ім. Ігоря
Сікорського) та відстань до нього. Змінивши координати на інше місто
(наприклад, Львів), переконайтесь, що результат змінюється відповідно.
