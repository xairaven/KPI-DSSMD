# Лаб. 4 — Абітурієнт (елементи управління)

Android-додаток на Tauri (Rust + React/TypeScript), побудований на основі
Лаб. 3. Домен: абітурієнт (ID, Прізвище, Ім'я, По-батькові, Адреса,
Телефон, Оцінки).

Завдання додає до Лаб. 3 елементи управління `Button`, `TextView`,
`EditText` та `ListView`. Ці типи елементів фактично вже використовувалися
в застосунку з Лаб. 2 (форма введення, таблиця зі списком), тож для цієї
роботи їх явно виокремлено в новий екран — пошук абітурієнта за
прізвищем, — а не позначено заднім числом у вже наявних формах.

## Структура

- `src-tauri/src/applicant.rs` — Model: сутність `Applicant` і чисті
  функції бізнес-логіки (середній бал, незадовільні оцінки, поріг,
  напівпрохідний бал). Нічого не знає про Tauri чи UI.
- `src-tauri/src/repository.rs` — Model: спільне мутабельне сховище
  (`Mutex`, керований стан Tauri), ініціалізоване даними з файлу.
- `src-tauri/src/sample.rs` — початковий масив із 10 абітурієнтів,
  використовується як запасний варіант, якщо файл даних відсутній
  або пошкоджений.
- `src-tauri/src/storage.rs` — Model: читання/запис абітурієнтів у
  JSON-файл (`applicants.json`) у каталозі даних застосунку.
- `src-tauri/src/screen/` — Controller: по одному модулю на кожен пункт
  завдання плюс екран введення/редагування та екран пошуку:
  - `failing.rs` → (a) незадовільні оцінки
  - `threshold.rs` → (б) поріг середнього балу
  - `top.rs` → (в) топ-N та напівпрохідний бал
  - `students.rs` → список, додавання, редагування, видалення
  - `search.rs` → пошук за прізвищем (новий у цій роботі) — демонструє
    всі чотири елементи управління в одному прикладі
- `src-tauri/src/lib.rs` — читає `applicants.json` під час `setup()`
  (перед тим, як стан стає керованим), підписується на
  `RunEvent`/`WindowEvent`, щоб журналювати зміни стану життєвого циклу
  Activity, і зберігає дані у файл при `Suspended`/`Exit`/`CloseRequested`.
- `src/screens/` — View: `Home.tsx` (меню), та по одному екрану на
  кожен Controller вище. Жодної бізнес-логіки, лише відображення та
  виклик `invoke()`.
  - `Search.tsx` — новий екран: `EditText` (поле вводу прізвища) +
    `Button` ("Пошук") фільтрують `ListView` (клікабельний список
    `ul.list-view`/`li`, а не таблиця); вибір елемента списку заповнює
    `TextView` (окремий блок деталей лише для читання).
- `src/components/ApplicantTable.tsx` — спільна таблиця, яку
  перевикористовують екрани звітів (a/б/в та список абітурієнтів).

## Запуск

```sh
pnpm install
pnpm tauri android dev   # Android-емулятор
pnpm tauri dev            # десктоп, для швидкої перевірки
```

### Перевірка

На головному екрані з'явиться новий пункт меню "Пошук". На ньому введіть
частину прізвища абітурієнта в поле вводу й натисніть кнопку "Пошук" —
список нижче скоротиться до відповідних абітурієнтів. Клік на елементі
списку виведе під ним повну інформацію про вибраного абітурієнта.
